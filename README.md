# Radchenko-Windows-82-Origial-
Программная детерминированная симуляция архитектуры Intel 8086 на чистом GDScript. Независимая аппаратная модель регистров и адресного пространства bytearray без системных вызовов OS.execute. Автор: Н. Радченко. Приятного испозованые мои эмуляторы.
Добро пожаловать медленный, неточный  и неполный но настоящий мой эмулятор dos
тут за сильное ограничение можете принять вызов создание файлы.com включая тежялые игры
вы можете даже изменит моё ядро код
если вам не нравиться вы можете удалить мой код которые вы скачали
эти весь код в любые версии написаны полностью языке godot
код полностью открыт и мои прав нет
На Pc RE1.0 с помощью res вы может запускать реальные файлы на андроиде
Чтобы поставить мой эмулятор следуйте по шагам:
1.скачайте godot либо 4.7 с официального сайта либо из Google play
2. возьмите мой код(выберете версию, для андроид вам нужно линейка RE, чем новее версия, тем вы можете запускать реальные файлы посерьезне)
3.создайте узел:control 
4. поставьте мой код прямо скрипт control 
5.запускаете
готово 
на windows:
1.войдите в power shell
2.напишите run
3.напишете y для соглашение открытие проводника
4.выберайте файлы.com/Exe 16бита
как только выбрали он запустит 
на андроиде:
1.поставьте файлы.com/Exe 16бита в такие адреса:
Внутреная память/Documents/ваш проект godot которые вы создали/вставьте вот здесь
2.найдите dos launcer
3.как только вы зашли выберете файлы которое вы поставили посмотрев адрес
4.нажмите run
готово
